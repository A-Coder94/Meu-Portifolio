# AS Soluções Tecnológicas

Site institucional estático. Os arquivos `index.html`, `styles.css`, `script.js` e `logo.png` ficam na raiz do projeto.

## Publicação na Vercel

1. Importe o repositório do GitHub na Vercel e selecione a pasta raiz do projeto.
2. Escolha **Other** como framework preset.
3. Deixe os comandos de build e instalação vazios; não há etapa de compilação.
4. Se a Vercel solicitar um diretório de saída, informe `.` (raiz do projeto).
5. Publique. A Vercel disponibiliza uma URL e publica automaticamente novos pushes para a branch de produção.
